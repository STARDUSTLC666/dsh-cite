# dsh-cite 验证记录

本页整理原 README 的历史验证说明，保留当时的版本、日期与范围。自动测试、启动检查、浏览器操作和真实服务验收分别记录，不能相互替代。更详细的版本验收文件仍保留在仓库中。

## 0.4.0（2026-10-03）

- Windows：40 项自动测试全部通过，无跳过。覆盖嵌套 BibTeX、宏、机构作者、复合姓氏、畸形输入、容量边界、精确与候选重复、并发修订冲突、部分失败重试、取消不写入、元数据差异保留和英文错误信息。
- 宿主契约：官方源码构建的 RC2（639ed015）和公开 npm 包 `0.2.1-alpha.1` 均在 E 盘隔离环境测试；18 插件共同注册 110 工具、35 技能，19 输出样例通过 schema 检查。未配置真实账号的健康检查可返回未配置，这不表示真实服务连接通过。
- 可见浏览器操作：官方 alpha 的设置页中实际上传 `.bib`、本地预览、选择保存、关闭 / 重开设置保留输入、搜索、引文预览及三种下载。DOI 大小写与链接形式的重复被跳过，错误行不可保存。中英文切换使用同一份两条题录的文献库，修订与原始资料未改变；390px 布局另作可见检查。
- 真实 Crossref：显式查询 `10.1038/nature12345`，作者、年份等空字段已补全；本地测试标题被保留，实际提供者标题作为差异显示。曾出现网络请求失败，重试后成功；不把网络波动当作已定位或修复的代理问题。没有 DOI 的条目显示单独失败。
- 备份核对：从实际下载取得的 JSON 包含两条文献、修订 2、原始 `.bib`、已填字段和标题差异；原始来源逐字保留。测试题录为合成数据，不能作为实际论文元数据使用。
- 生产依赖审计无已知漏洞。Citation.js 与 proper-lockfile 均使用 MIT 许可。

边界：本轮没有操作用户原生桌面窗口，没有上传真实文献库，也没有配置模型密钥。网页验证和桌面来源检查不能替代桌面新工作台的可见操作验收。四种引文采用基本模板，没有声明覆盖各期刊的全部规范。
